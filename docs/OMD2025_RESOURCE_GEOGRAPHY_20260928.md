# 全球三大作物秸秆资源：2020 年可复算空间基线

日期：2026-09-28。本文给出**理论产生量**与当前还田试验文献覆盖的空间比较；不将资源量误写为可收集量、焚烧量或管理路径采纳率。可汇报图为[组图](../figures/omd2025_resource_evidence/resource_evidence_geography.png)，另有无编号玉米、水稻和小麦单图，数据和脚本均在仓库。

## 来源与统一口径

- 国家—作物—年份秸秆产生量：[Sileshi 等 2025 年 OMD 研究](https://doi.org/10.5194/essd-17-369-2025)及[Zenodo 记录 10450921（Version 2）](https://doi.org/10.5281/zenodo.10450921)。数值为以粮食产量和作物关系式估计的地上部秸秆**干重理论产生量**，单位吨/年。原始文件 SHA-256 为 `0c95f45530631148f02e0a3906a53a60ceae4c1c18700ae05cc70906f6d0dec6`。
- 空间分配：[MapSPAM 2020 v2r2](https://doi.org/10.7910/DVN/SWPENT)灌溉/雨养生产量栅格。对每个国家×作物，将 OMD 2020 年秸秆吨数按该国 MapSPAM 同作物各格网的粮食生产量比例分配，汇总到 0.5°；这一步是**模型化降尺度**，不是格网实测秸秆量。
- 气候/季节分层沿用本项目已接入的 Köppen–Geiger 1991–2020 气候带及 GGCMI Phase 3 典型作物历。仅玉米使用单一成熟季度；水稻、小麦的多季候选没有拆分吨数。
- 文献空间对照使用 [Encarnation 等公开二次数据](https://github.com/davidencarnation/sustainable_ag_SOC_yield_meta_analysis)中“直接还田相对移除、产量与 SOC 均可用”的原始论文标题。每个作物×大洲内按完整标题去重，不把 1,185 个效应或多个 Study_ID 当作独立论文；同一篇可涉及多个作物，三作物标题数不可相加。

## 已得到的资源规律

| 作物 | 2020 理论秸秆产生量 | 最集中的区域 | 次级重点区域 |
| --- | ---: | --- | --- |
| 玉米 | 13.20 亿吨 | 美洲 48.8% | 亚洲 31.5% |
| 水稻 | 11.23 亿吨 | 亚洲 88.0% | 非洲 7.0% |
| 小麦 | 12.63 亿吨 | 亚洲 45.8% | 欧洲 33.0%；美洲 15.6% |

三作物合计 **37.06 亿吨干重**。OMD 2015–2020 国家×作物×年筛选表有 **2,409 行**，2020 年 **402 行**；其中 393 个国家×作物组可与 MapSPAM 格网生产量联结。约 **99.9969%** 的 OMD 2020 总吨数完成空间分配，已分配组的最大相对质量守恒误差为 `1.97×10⁻¹⁶`。0.5° 灌溉/雨养作物格网共 85,493 行，85,052 行得到 OMD 分配量。小份额未联结组保留在审计表，不通过邻国或全球均值填补。

分气候带的模型化份额：玉米在 Köppen D/C/A 类分别约 43.1%/27.4%/17.8%；水稻在 C/A 类约 43.5%/43.2%；小麦在 C/D/B 类约 40.4%/35.5%/22.2%。这些是资源的空间分层，并不能证明气候改变田间管理效果。

## 资源—证据的可量化错位

| 作物×地区 | 2020 秸秆资源占该作物全球份额 | 现有还田双结局来源标题占该作物份额 |
| --- | ---: | ---: |
| 玉米×美洲 | 48.8% | 6.4%（7/109） |
| 玉米×亚洲 | 31.5% | 78.0%（85/109） |
| 小麦×欧洲 | 33.0% | 1.9%（2/107） |
| 小麦×亚洲 | 45.8% | 94.4%（101/107） |
| 水稻×亚洲 | 88.0% | 97.2%（69/71） |

这给出一条具体的文章结论：**全球秸秆资源中心与可用还田双结局试验证据中心并不总重合**。美洲玉米、欧洲小麦值得作为跨区域原文提取和外推验证优先区；水稻资源与证据都高度集中于亚洲，但非洲稻作的证据相对少。这里比较的分母分别是模型化资源吨数和所选公开数据集的唯一标题，不能把“低论文占比”解释为该地区不存在研究、政策失灵或管理效果更差。

## 对主文章和政策模块的作用

资源层回答“秸秆在哪里、哪类作物、哪类气候/季节”，全文效应层回答“路径对产量、SOC、温室气体有什么影响”。两层先保持隔离，只有在地区、作物、土壤与制度适用域得到支持后，才能做效应外推。政策分析将进一步把理论产生量与**可收集/竞争用途/实际露天焚烧**分别联结，识别优先治理地区；绝不能直接用本图的蓝点当作可供生物炭转化或可避免焚烧的吨数。

[Smerald 等全球谷物残体管理数据](https://doi.org/10.35097/989)的作者默认格网文件已在下一步[完成接入与复算](SMERALD2023_MANAGEMENT_20260928.md)，补齐谷物合计的留田、饲料/垫料、其他离田和焚烧背景。该源是谷物合计口径，仍不能未经独立归因直接给水稻、玉米、小麦分别赋值。此后对接官方政策文本、辖区及生效年份。

## 复算和产物

先运行 `python scripts/download_omd_mapspam_sources.py` 下载/校验本轮新增的三个源文件；其余 FAOSTAT 桥接、MapSPAM 面积格网、Köppen/GGCMI 中间文件沿用项目既有[全球背景工作流](GLOBAL_PATTERNS_20260928.md)。然后运行 `python scripts/integrate_omd_residue_geography.py`、`python scripts/analyze_resource_evidence_alignment.py` 和 `python scripts/plot_omd_resource_evidence.py`。主要表在 `data/processed/omd2025_residue_geography/`；`manifest.json`、`alignment_manifest.json` 记录原始文件哈希、统计口径和边界。原始大文件及逐格网全表本地留存但不入 Git；共享仓库保留关键汇总、脚本、测试与图。图形使用用户指定的蓝/粉配色、组版对齐后拆分，无图号。
