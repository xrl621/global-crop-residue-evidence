## 重点整合：Lu 2020 产量数据

来源：[Lu 2020, PLOS ONE](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0231740)；数据 DOI：`10.1371/journal.pone.0231740.s002`。本地输入为原工作簿及原作者参考文献附件。

已完成的核查：

- 从原始 XLSX 重新读取 **153 条处理—对照产量记录**，逐行核对均值、SD、重复数、lnRR 和方差；153 条均值比与153条方差均算术一致。
- 原表脚注明确：粗体误差值使用平均 CV 估计。据实际单元格字体识别出 **108 条含插补 SD，45 条非粗体**。非粗体只能标作“来源报告或由 SE 换算”，不能说已经逐篇原文验证为实测 SD。
- 改进参考文献解析，修复 `In search…` 被截成期刊名等问题。**138 条记录可唯一对应原作者参考文献中的作者—年份组合**；其余保留候选，不硬配 DOI。
- `Lu2020_10/19` 存在同姓同年参考文献歧义；`Lu2020_28` 原表为 Zhang 2018，但附件没有对应作者年份。不能凭类似题名擅改成 Zhang 2015。
- `Teramo` 被填入国家栏，且另一篇题名明确为黄土高原试验的记录也沿用该字段。本轮保留原值，规范国家留空，不据此宣称新增意大利试验。
- 涉及不同耕作、地膜、双空行等处理的来源先标记对照复核。墨西哥来源还涉及保留、移除、焚烧对照的辨别，不能仅依二次表“无秸秆”自动确定对比。

在三作物、秸秆原料、可识别参考文献、数值一致及保守处理筛查后，形成 **62 条/15 个来源论文组的二次数据描述层**：

| 作物 | 记录数 | 其中含来源插补误差 | 非粗体来源误差 |
| --- | ---: | ---: | ---: |
| 玉米 | 22 | 15 | 7 |
| 水稻 | 12 | 7 | 5 |
| 小麦 | 28 | 25 | 3 |
| 合计 | **62** | **47** | **15** |

这62条是153条中完成本批来源级筛查的子集，并非新增发现62条原始观测。允许检查来源内的均值比、单终点覆盖；**不并入原文审核主库、不做逆方差全球合并、不把15个来源论文组当成15个已核实独立试验**。原论文有田间等纳入条件，但处理双方的完整管理、共同试验和年份依赖仍需原文或更完整元数据解决。原表153条与原文报告146条产量比较的差异尚未解释，必须保留提示，不能称已完整复现原论文结果。

## 其他来源的整合结果

- BiocharDS：来源 `B` 编码按原工作簿 Treatment 页解释为“处理相对于对照的生物炭增量”，不等于两组都完全不施肥；保留原料、核心作物和复合干预标签。未把全部试验默认成田间。
- 33165164 等仅给 `RR` 的列继续保留原数值；缺少明确定义时不猜是 lnRR，更不自动再次取对数。
- GWP/GHGI/CO2 的边界与一级 CH4、N2O 分开；SOC 浓度与储量分开。
- Li2022 的 822 条历史“疑似重复”标记产生在更早的工作表展开层。对现存830条重新核查，相同数值键相关的记录为256条；加入完整可用环境/管理信息后，本轮没有确认可安全进一步合并的跨表重复。**既不把822条全删，也不把256条直接视为重复试验**。
- 跨来源相同题名及相同论文/指标/效应量只建立复核链接，不自动删除，因为多剂量或多年度可能恰有相同数值。
- 主库优先：与主库同论文的二次来源记录不作为新增描述证据。题名精确链接可能漏掉翻译、拼写、重复发表，后续仍需更完整 DOI 与地点/年份审计。

## 层级与查询边界

| 层级 | 条数 | 用途 |
| --- | ---: | --- |
| PRIMARY_STRICT_DESCRIPTIVE | 437 | 延续已有严格描述集，不改变其统计保证 |
| PRIMARY_REVIEWED_HELD | 116 | 原文已处理但尚有分析条件不满足 |
| SECONDARY_SOURCE_AUDITED_DESCRIPTIVE_ONLY | 62 | 本批来源级核验后的独立二次描述层 |
| SECONDARY_NUMERIC_PREPARED_NOT_ADMITTED | 1,052 | 数值与核心范围初筛通过；田间、误差、独立性等未完成 |
| SECONDARY_HELD | 11,286 | 口径不明、扩展结局、身份、原料或数值等需处理 |

后两层不是“全部数据无效”，而是按当前用途分层；例如酶活与稳定性可在机制或扩展分析中使用，但不能混入产量均值。1,052 条也不是已经新增的正式效果。

SQLite 查询示例：

```sql
-- 保持原文审核分析边界
SELECT pathway, outcome, COUNT(*) AS rows,
       COUNT(DISTINCT experiment_id) AS trial_keys
FROM primary_strict GROUP BY pathway, outcome;

-- 单独检查二次描述层，绝不与上表 UNION 后做正式模型
SELECT crop, variance_origin, COUNT(*)
FROM secondary_descriptive GROUP BY crop, variance_origin;

-- 按论文追踪各来源别名和潜在重复
SELECT * FROM source_paper_aliases WHERE paper_id = ?;
```

主库有些旧记录还不能可靠组合处理臂/年份，因此整合表将这些原记录分别保留，不新造跨终点配对。原有联合分析继续使用已审核的专用配对流程。

## 复现、技能与共享

运行 `python scripts/integrate_evidence_batch1.py`，输出位于 `data/processed/integration_batch1_20260927/`，生成 SQLite 和对应 CSV。脚本需要工作区现有的7源注册表、原始 Lu 工作簿/参考附件与各源元数据；公开仓库单独克隆后，在补齐这些输入前不能完整重建整合数据库。`manifest.json` 保存输入与输出哈希。

Nature data 技能要求的来源、版本、许可与定位信息保留在 `sources.csv`、`provenance.csv` 和逐行字段中。第三方文件未被重新许可。完整二次数据导出及SQLite留在本地，不随本批发布；公开代码、摘要计数及方法历程不等同公开全部第三方数据。

37项测试通过（其中8项为本批新增），包含原库哈希不变、记录守恒、层级隔离、字体插补标志、数值重算、歧义参考文献、非法国家字段和SQLite完整性。
