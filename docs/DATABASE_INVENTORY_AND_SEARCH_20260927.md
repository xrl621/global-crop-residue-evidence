# 数据库体量与公开来源检索核查（2026-09-27）

## 核心结论

“真正新增 1 项独立试验”指上一批主库的去重试验键从 **32 增至 33**，不是整个数据库只有 1 项，也不是新增了 43 个独立试验。上一批 43 条新增终点记录包含 Dong 既有试验的 18 条产量、Yang 既有试验的 8 条 GWP/GHGI，以及 Sun 新试验的 17 条记录。补充旧试验的指标有助于联合分析，但没有增加相同数量的独立试验覆盖。

此前只报告 553 条主库记录，未同时交代工作区已有的大型候选数据库，不能充分反映项目体量。实际情况是：**正式筛查层仍小、地域偏窄；候选层已达万条，主要瓶颈是批量整合与核验，而非完全缺少可获取的数据。**

本次做本地盘点和公开来源检索，不改变主库纳入规则，不将检索命中自动入库，不提交远端更改。使用 Nature 文献检索技能进行多来源发现，按 Nature data 的来源与可用性核查要求区分“已下载、已整理、已筛查、可分析”。

## 1. 计数单位必须区分

| 单位 | 含义 | 不能怎样计数 |
| --- | --- | --- |
| 来源论文 | DOI 优先，缺 DOI 时用来源 URL/标题标识 | 同一试验的多篇论文不能自动算多个试验 |
| 去重试验键 | 结合地点、试验设置与时间识别的实验单元；当前以 study_id 计数 | 一篇论文可能有多个试验；同一地点也可能有不同试验 |
| 处理—对照对比 | 同一环境、年份或季节、可比管理条件下的两个处理臂 | 共享对照、多剂量、重复年份不具备完全统计独立性 |
| 终点效应记录 | 一个对比中的一个指标，如产量或 SOC | 同一对比的产量和 SOC 不能算两项独立试验 |
| 原始处理观测 | 单个处理臂的均值、环境或管理信息 | 未匹配对照之前不是一个处理效应 |

例如：一个固定试验，3 个剂量 × 3 年 × 2 个指标，可产生 18 条效应记录，但仍是 1 项试验。当前“33 项”是项目去重键的操作性计数，不代表已消除了所有共享对照与时间相关性。

## 3. 本轮公开检索及重点发现

### 检索范围与限制

- 检索日期：2026-09-27。Crossref 8 组主题查询，每组前 100 条，发表截止日设为 2026-09-27。
- DataCite 3 组字段查询，分别返回 107、476、75 条，已分页获取这三组的全部返回记录。查询之间有重叠。
- 最终 11 组 API 查询均成功，共 **1,458 条元数据返回**；标题关键词初筛并按 DOI 精确去重后 **932 个候选条目**。其中 5 个 DOI 与当前主库命中；其余不代表 927 个新合格试验。
- DataCite 年份过滤只精确到 2026 年；正式纳入前还需核对实际发布日期。预印本与正式版、数据版本与论文之间的关系尚未完全合并。
- 补充使用出版社、PubMed/PMC、Figshare、Dryad、Zenodo、机构库网页检索，追踪附件、全球综合和非亚洲试验。网页发现的重点来源单独保存，不冒充完整可复现的 PRISMA 检索计数。
- OpenAlex 请求遇到 429 限流；本轮未完成 Web of Science、Scopus、CNKI 的机构检索。Crossref 是相关性排序的有界检索，不是穷尽全部文献；932 个仅为候选，不是全文筛选后的纳入数。
- 完整查询、返回量、页数和 URL 见 `api_search_log.json`；不要使用 Crossref 宽泛检索的 total-results 作为本研究相关文献总数。

## 4. 现在应该改什么

1. **从零散补图转为批量入库。** 优先处理已有 BiocharDS、33165164、33684502 和水稻库，再接 PNAS 新来源；单位是“数据源 → 原论文 → 试验 → 处理臂 → 终点”，不是每轮只找一篇。
2. **单终点主库与联合子集分开。** 产量、SOC 浓度/储量、CH4、N2O 分别建立尽可能完整的数据集。联合分析只用可可靠匹配的子集；不为了三个终点齐全而丢掉大量单终点研究。
3. **保留二次数据库的价值。** 对变量明确、原始文献可追溯、数据许可允许的二次数据，进行标准化、自动一致性检查、风险导向原文核验，而不是无条件要求把所有单元格人工重新抄一遍。误差来源区分原文报告、可验证换算和原作者插补，不能把插补误差伪装成实测误差。
4. **先解决身份与依赖。** 跨来源 DOI/作者/地点/年份/处理臂去重；建立共享对照和重复年份关系，再选择多层模型或聚类稳健方法。最终新增独立试验数需等这一步完成，不能预先承诺几百项。
5. **有目标地补短板。** 优先非亚洲、玉米/小麦、焚烧直接对比和不同气候的独立试验，而非继续只补同一中国水稻地点的年份。
6. **机器学习放在有效样本与覆盖检查之后。** 数千行来自少量试验，仍不等于数千个独立训练样本；需要按试验/地点分组验证，防止同一试验跨训练测试集泄漏。

每个后续批次应固定报告：来源总行数 → 范围符合行数 → 去重后行数 → 可计算终点数 → 方差可用数 → 新增唯一试验/国家/作物数；并输出排除原因表。这样既能真实扩大数据量，也能看清工作是否增加了科学覆盖。
