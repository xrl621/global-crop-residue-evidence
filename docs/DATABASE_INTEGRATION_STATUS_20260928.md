## 下一批真正的“接入完成”标准

每个来源至少交付：固定版本/许可/源文件哈希、字段字典、处理脚本、可复算联结表、空间/时间匹配率、缺失与排除日志；效应来源另要给论文/试验身份去重与处理—对照、误差审计；政策来源另要给原文条款和生效时间。只下载文件或只在文中列链接，不再称“完整接入”。
