# 项目变更日志与决策历程

本文件采用**追加式记录**。新决定写在最上方；旧决定即使被替代也不删除。每次改变研究范围、来源、准入、模型、图稿或结论，写明“原口径 → 新口径”、原因、受影响文件/分析和验证情况，并同步更新[当前项目框架](PROJECT_FRAMEWORK_AND_ANALYSIS.md)。数字若是时点快照，必须标注日期和数据层级。

## 2026-09-23｜建立仓库主线与公开证据快照

**决定：** 以[当前项目框架](PROJECT_FRAMEWORK_AND_ANALYSIS.md)作为现行研究与分析路线；三条路径、三种作物、产量–SOC–GHG 联合问题不变。建立本日志，后续改变思路也留版本轨迹。公开 `literature/evidence_database.csv` 及字段、筛选协议、导出/盘点脚本；原始 PDF、全审计表和生成输出仍留本地。

**事实快照：** 428 条全文核验配对效应 / 26 项独立田间试验；414 个规范化论文身份属于更大的关系型候选库，4,345 条候选效应未经同等级审核；仅露天焚烧×产量有 19 条效应 / 10 项独立研究达到首轮合并计数门槛。22 条公开行方差来源待消歧，52 条带历史 pending 等级标签。此记录不把候选或研究内重复当成独立证据。

**为何这样做：** 先统一比较口径和统计单位，再持续扩大逐处理/季节的可信数据；避免旧图稿的探索性方向被误读成正式发现。

**影响与验证：** 以 `scripts/export_evidence_database.py --check` 校对公开投影，以 `scripts/describe_evidence.py` 按独立试验盘点；正式模型仍须解决依赖、方差来源和系统边界。旧[六图草案](../MAIN_FIGURE_STORYBOARD_6FIG.md)关于还田/生物炭方向和全球联合概率的措辞暂降为待验证设计，不是现行结论。具体分析与图的放行条件见主框架。

## 2026-09-22｜正式冻结三条管理路径

**原口径 → 新口径：** 早期主图偏重直接还田和生物炭，焚烧多作为背景/政策压力 → [三路径冻结说明](../SCOPE_FREEZE_THREE_PATHWAYS_20260922.md)确定直接还田、生物炭还田、露天焚烧均为正式目标；秸秆移除仅为参照，非第四路径。覆盖/留茬按可隔离的直接还田亚型；免耕是调节变量；堆肥暂不在主路径。

**原因与影响：** 回到课题最初的三处理问题，并分离焚烧后的田间效应与燃烧瞬时排放。受影响的是筛选、字段编码、模型对照、六图叙事和政策联结；旧文件保留历史语境，但不能覆盖此决定。随后首个达到计数门槛的是露天焚烧×产量；平均效应对异质性和逐研究剔除敏感，不得解释为普遍焚烧增产。
